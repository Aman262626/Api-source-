🤖 Telegram AI Bot

AI-powered Telegram bot deployed on Vercel

Bot Commands

/start - Welcome message
/ask <question> - Get AI response
/help - Get support
/admin - Contact admin
/live - View members count

Setup Steps

  1. Create a bot via @BotFather on Telegram
  2. Deploy this repo to Vercel
  3. Add BOT_TOKEN in Vercel Environment Variables
  4. Visit /api/setwebhook once to activate the bot
