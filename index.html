⚡ AI API Gateway

Unified API proxy for OpenAI & Anthropic models

📡 Endpoints

POST /api/chat Send chat completions
GET /api/models List available models
GET /api/health Health check

🚀 Quick Start

curl -X POST https://YOUR_DOMAIN/api/chat \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "system", "content": "You are a helpful coding assistant."},
      {"role": "user", "content": "Write a Python function to sort a list"}
    ],
    "stream": false
  }'

🔧 Setup

1. Deploy this project to Vercel
2. Go to Vercel Dashboard → Settings → Environment Variables
3. Add your API keys:
   - OPENAI_API_KEY=sk-...
   - ANTHROPIC_API_KEY=sk-ant-...
4. Redeploy the project
5. Use your Vercel URL as the API endpoint

💡 Usage Examples

Python

import requests

response = requests.post(
    "https://YOUR_DOMAIN/api/chat",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "claude-sonnet-4-20250514",
        "messages": [
            {"role": "user", "content": "Explain async/await in JavaScript"}
        ]
    }
)
print(response.json())

JavaScript (fetch)

const response = await fetch("https://YOUR_DOMAIN/api/chat", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer YOUR_API_KEY"
  },
  body: JSON.stringify({
    model: "gpt-4o",
    messages: [
      { role: "user", content: "Write a React component for a todo list" }
    ],
    stream: true
  })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  console.log(decoder.decode(value));
}
